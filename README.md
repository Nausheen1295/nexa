# NEXA

**An AI assistant that answers questions about my work, and only from my documented work.**

💬 **Live site:** https://nausheen1295.github.io/nexa/

NEXA answers questions about my projects, skills and experience, in the style you need: recruiter, developer, simple, architecture or interview. It uses retrieval-augmented generation over my portfolio's documentation, cites its sources, and says so when something isn't documented instead of guessing.

Part of the AI Lab in my portfolio, [NEXUS](https://nausheen1295.github.io/portfolio/), where NEXA also has its own panel.

## Two ways it answers

| | Documentation search (works now) | AI answers (once the API is hosted) |
|---|---|---|
| How | BM25 search in the browser over the knowledge base | NEXA API: retrieval → LLM → citation check |
| Output | The best-matching passages, with links | A written answer in the chosen mode, with verified sources |
| Never | Imitates AI | Cites a document it didn't retrieve |

Both modes say plainly when a detail isn't documented. The site checks the API on load and switches modes automatically, and it falls back to documentation search if the API is asleep or unreachable.

## Repository

```
index.html, css/, js/     the NEXA website (static, GitHub Pages)
  js/retrieval.js         BM25, ported line-for-line from the API so rankings match (parity-tested)
  js/config.js            API endpoint (null = documentation search) and knowledge URLs
knowledge/portfolio.json  bundled knowledge base (fallback)
backend/                  NEXA API: FastAPI, BM25 retrieval, grounded generation (see backend/README.md)
render.yaml               one-click Render deployment of backend/
```

The knowledge base is generated by the portfolio from its project data and each project's README, and published at `https://nausheen1295.github.io/portfolio/knowledge/portfolio.json`. Both the website and the API load that live copy, and fall back to the bundled one.

## Turn on AI answers

1. **Deploy:** go to https://render.com/deploy?repo=https://github.com/Nausheen1295/nexa and enter `ANTHROPIC_API_KEY` and `NEXA_MODEL` when asked. They are stored only in Render.
2. **Check:** `https://<service>.onrender.com/health` should return `{"status":"ok"}`.
3. **Connect:** set `endpoint` to that address in `js/config.js` here and in `js/nexa/config.js` in the portfolio repo, then push.

Full details, settings and the security checklist are in [backend/README.md](backend/README.md).

## Tests

```bash
npm test                 # website retrieval: tokenizer, parity with the Python ranking, offline answers
cd backend && pip install -r requirements-dev.txt && pytest   # 39 API, safety and retrieval tests; no key or network needed
```

## Security

- **Secrets:** the API key lives only in the host's environment variables. Nothing secret is in this repo or the website.
- **Request limits:** CORS allow-list, strict validation, a 32 KB body cap, and per-visitor rate limits per minute and per day.
- **Prompt injection:** documents and questions are treated as data, never as instructions, and citations are checked server-side.
- **Logging:** logs record counts and latency, never question text.
